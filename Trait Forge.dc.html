I.

Triage first

A new voice is expensive. Twenty-four exist, and each one needs a line in every scene or it sits silent and makes the roster feel thinner rather than fuller. So before the template, one question: does this want to be its own voice, or is it the thing an existing voice was missing?

Three tests. Does it want different things from every existing voice, or the same thing in a different accent? An accent is a diction note on an existing voice, not a new one. Can it disagree with its nearest neighbour — if you cannot write the argument between them, they are one voice. Does it have a Thought at the end that is not already on the table.

Bloodline passes all three, which is why I pre-filled it rather than folding it into Adrenal. My read is in the margin — argue with it.

IV.

When a trait is better off folded in

Not every good idea is a voice. Some are the missing half of one that already exists, and folding them in is the better outcome — it deepens a voice you already pay for rather than adding one you have to feed.

The tell is the wants field. If it matches an existing voice and only the diction differs, it is an extension. Historiography wanting the log and Falsification wanting the log disproved are two voices. Historiography citing dates and Historiography citing case numbers is one voice with two moods.

Set the verdict field to fold into and name the host in the overlap field. I will add the register as a second mode of that voice, which is cheaper and usually reads better.

Would fold in

A voice that wants precedent and cites archives. That is Historiography with a different reading list.

Would not

Bloodline. Its only mode of expression is physical, which nothing else in the roster has, and it would be the first voice that moves an axis by magnitude rather than direction — rupture regardless of which side you answered from.
